# Отчет по лабораторной работе

## Тема и цель

Создать простую объектную модель онлайн-кинотеатра, диаграмму классов, обработку ошибок и сохранение данных в JSON и XML.

## Классы

| Файл | Класс | Назначение |
| --- | --- | --- |
| `movie.py` | `Movie` | Фильм: название, жанр, год |
| `user.py` | `User` | Пользователь: имя, наличие подписки, просмотренные фильмы |
| `cinema.py` | `Cinema` | Списки фильмов и пользователей, добавление и поиск |
| `errors.py` | `CinemaError` | Собственное исключение для ошибок кинотеатра |

Каждый класс находится в отдельном файле. `main.py` показывает меню, а `storage.py` содержит функции чтения и записи файлов. Итоговая диаграмма `online_cinema.drawio` показывает классы, поля, методы и связи. Кинотеатр содержит много фильмов и пользователей. Пользователь может просмотреть много фильмов.

## Логика работы

При добавлении фильма проверяются название, жанр и год. При добавлении пользователя указывается наличие подписки. Метод `User.watch()` записывает название фильма в историю, если подписка есть. Метод `Cinema.find_movie()` и `Cinema.find_user()` ищут объекты по названию или имени. Имена пользователей и названия фильмов должны быть уникальными.

## Структура JSON и XML

JSON содержит объект со списками `movies` и `users`. Фильм записывается как объект с `title`, `genre`, `year`. Пользователь записывается как объект с `name`, `has_subscription`, `watched`.

XML содержит корневой элемент `<cinema>`. В `<movies>` лежат элементы `<movie>` с названием, жанром и годом. В `<users>` лежат элементы `<user>` с именем, признаком подписки и списком просмотренных названий. Примеры приведены в `sample_data.json` и `sample_data.xml`.

## Исключения

`CinemaError` возникает при пустых данных, повторном названии или имени, отсутствии фильма или пользователя и просмотре без подписки. В `main.py` также обрабатываются встроенные `ValueError` (например, текст вместо года), `OSError` (ошибка файла), `json.JSONDecodeError` и `xml.etree.ElementTree.ParseError` (поврежденный файл). После ожидаемой ошибки меню показывается снова.

## Проверка и вывод

Команда запуска из папки проекта: `python3 main.py`. Проверены запись и чтение JSON и XML, а также ошибка просмотра без подписки и неверный ввод года. Задание выполнено: классы разделены по файлам, диаграмма соответствует коду, данные сохраняются в двух форматах, ошибки обрабатываются.

## Краткие ответы для защиты

1. **Что такое класс?** Описание данных и действий объекта. Например, `Movie` описывает фильм.
2. **Что такое объект?** Конкретный фильм или пользователь, созданный по классу.
3. **Для чего нужен `__init__`?** Он записывает начальные данные в новый объект.
4. **Что такое `self`?** Текущий объект, с которым работает метод.
5. **Что такое метод?** Функция внутри класса, например `User.watch()`.
6. **Зачем нужен `CinemaError`?** Чтобы явно сообщать об ошибках предметной области.
7. **Зачем нужен `try/except`?** Чтобы показать сообщение об ошибке и продолжить работу программы.
8. **Чем отличаются JSON и XML?** JSON использует объекты и списки; XML использует теги. Здесь они хранят одни и те же данные.
9. **Что означает 0..* на диаграмме?** Объектов может быть сколько угодно, включая ноль.
